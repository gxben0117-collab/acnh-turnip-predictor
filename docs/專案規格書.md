# 動物森友會－大頭菜價格預測器　專案規格書

Animal Crossing Turnip Predictor

版本：V1.00　建立日期：2026-09-10

> 本文件是給後續開發（含 Codex／其他 AI 協作者）的完整需求規格，整理自專案發起人的原始需求描述。
> **演算法必須以 [演算法原始數據規格表.md](演算法原始數據規格表.md) 與 [../vendor/ac-nh-turnip-prices/](../vendor/ac-nh-turnip-prices/)
> 的原始碼為準，禁止自行憑印象簡化或重新發明四種 Pattern 的公式。**

## 一、專案目的

建立一個獨立網頁工具。玩家每週日購買大頭菜後，輸入：

- 週日購入價格
- 週一 AM／PM
- 週二 AM／PM
- 週三 AM／PM
- 週四 AM／PM
- 週五 AM／PM
- 週六 AM／PM

每新增一筆價格，系統立即重新計算目前仍可能存在的價格模式，預測後續價格範圍，並給玩家簡單明確的出售建議。

第一版不使用 AI、LLM 或付費 API。所有預測使用《集合啦！動物森友會》大頭菜價格生成演算法完成。

## 二、核心原則

- 不使用「連跌三次＝大漲型」這類 heuristic 規則判斷。
- 必須建立真正的 Pattern 模型，依據已知價格逐筆排除不可能的價格路徑（貝氏排除法，見演算法規格表第 5 節）。
- 以成熟的 Turnip Prophet（`ac-nh-turnip-prices`）演算法為基準，不自行簡化公式造成預測結果與成熟預測器不同。
- 四大 Pattern：波動型（Fluctuating）、大漲型／三期型（Large Spike）、遞減型（Decreasing）、小漲型／四期型（Small Spike）。
- 必須考慮遊戲價格取整方式（`intceil`）、倍率區間、Pattern transition probability 等細節，全部細節見演算法規格表。

## 三、首頁輸入區

頁面最上方：

- 「本週大頭菜購入價」：數字輸入框，單位鈴錢。
- 「知道上週價格型態嗎？」：選項為「不知道／波動型／大漲型／遞減型／小漲型」，預設「不知道」。

## 四、本週價格輸入

- 手機友善介面，星期一到星期六，每天 AM／PM 各一個輸入框，共 12 個價位時段。
- 允許未來價格保持空白。
- 每輸入或修改一筆資料，自動重新計算，不需要按「分析」按鈕。
- 輸入資料用 `localStorage` 保存，重新整理網頁後不消失。
- 提供「清除本週資料」按鈕，需二次確認避免誤刪。

## 五、預測結果

- 顯示本週最可能型態，例如：
  - 🔥 大漲型 62%
  - 📈 小漲型 21%
  - 〰️ 波動型 12%
  - 📉 遞減型 5%
- 百分比必須來自實際模型計算（演算法規格表第 5 節的正規化機率），不可硬編碼。
- 資料不足時顯示：「目前資料不足，仍有多種價格型態可能。」不假裝已經能準確判定。

## 六、未來價格預測

每個尚未發生的時段顯示：

- 預測最低價格 / 預測最高價格（理論可能範圍，見演算法規格表第 5 節第 5 點）
- 較可能價格區間（高機率範圍，需另外用機率加權計算，見演算法規格表第 5 節第 6 點）

「理論可能範圍」與「高機率範圍」必須分開顯示，不能讓極低機率的極端價格誤導使用者以為那是主要預測。

## 七、最佳出售時段

建立「🎯 建議出售策略」區塊，系統分析目前價格與所有仍可能的未來路徑，輸出：

- 目前價格
- 購入價格
- 目前損益
- 未來可能最高價
- 最值得觀察時段
- 目前出售建議

## 八、出售建議等級

四個狀態，判斷依據必須是「現在出售收益」vs「所有可能未來路徑的期望收益與下跌風險」比較，不能只用固定價格門檻：

- 🟢 繼續持有：目前仍存在明顯更高價格的合理可能性。
- 🟡 可以出售：已有不錯利潤，但仍有一定上漲空間。
- 🟠 建議出售：目前價格已接近模型中的高價區域，繼續等待的風險開始增加。
- 🔴 強烈建議出售：目前價格已位於高峰或極高價格區域，等待下一時段的風險高於潛在收益。

## 九、玩家風險偏好

出售策略選項：保守／平衡（預設）／冒險。

- 保守：較早鎖定獲利。
- 平衡：考慮期望收益與風險。
- 冒險：願意承擔較大下跌風險追求大漲高峰。

同一份價格資料可能因策略不同而產生不同出售建議，但 **Pattern 預測機率本身不能因風險設定改變**（風險偏好只影響
出售建議層，不影響演算法層）。

## 十、趨勢圖

- X 軸：一AM／一PM／二AM／二PM／三AM／三PM／四AM／四PM／五AM／五PM／六AM／六PM。
- 顯示實際已知價格，以及未來預測價格範圍，清楚區分「實際價格」與「預測區域」。
- 標記購入價格基準線。

## 十一、重要警告功能

- 判斷可能進入大漲階段：「🔥 偵測到大漲型可能性正在提高」
- 接近大漲中心高峰：「🚨 高峰警告」
- Pattern 顯示可能已越過高峰：「⚠️ 高峰可能已經結束」
- 接近週六最後時段仍持有：「🚨 本週即將結束」，提醒大頭菜過週會腐爛。

## 十二、技術架構

- 第一版優先：HTML／CSS／JavaScript 或 TypeScript；如需框架用 React + TypeScript。
- 預測核心必須與 UI 分離，建議目錄：

  ```text
  /src
    /engine
      patterns
      predictor
      probability
      sellStrategy
    /components
    /data
  /tests
  ```

- 核心預測器應可單獨測試，不要把 Pattern 計算全部寫在 React component 裡。
- 本專案目前的實際目錄骨架見 [../README.md](../README.md) 的「結構」章節（已依此規格建立空目錄，內容留給 Phase 2 開發）。

## 十三、測試

- 演算法正確性是本專案最重要的部分，需建立 automated tests。
- 測試涵蓋：購入價＋12 個已知／部分已知價格 → 驗證 Pattern 判斷、Pattern probability、未來價格 min/max、高峰位置。
- 移植既有開源演算法時必須保留來源與 License 資訊（見 [License說明.md](License說明.md)）。
- 用多組案例與 Turnip Prophet 官方網站（<https://turnipprophet.io/>）交叉驗證，相同輸入應得到一致的 Pattern 與價格範圍。
- 詳細測試基準見 [演算法原始數據規格表.md](演算法原始數據規格表.md) 第 7 節。

## 十四、UI

- 整體採用 Animal Crossing 柔和、可愛、清楚的視覺語言，但不得複製任天堂受版權保護的 UI、美術素材、Logo 或角色圖。
- 手機優先，iPhone 直式畫面必須容易操作，數字輸入框要大。
- 首頁資訊優先順序：
  1. 現在該不該賣
  2. 最可能 Pattern
  3. 最值得觀察的下一個時段
  4. 預測最高價
  5. 詳細 Pattern probability
  6. 完整價格圖表

## 十五、第一階段不做

AI／ChatGPT API、帳號系統、資料庫、多人系統、雲端同步、付費功能。第一版目標只做穩「輸入價格 → 正確預測 →
告訴玩家什麼時候賣」。

## 十七、後續可加功能（第一版演算法確認正確後再加）
