# 開發日誌 V1.01

日期：2026-09-10

## 背景

使用者家人正在實機玩大頭菜買賣，需要盡快有一個能用的網頁工具，因此把原訂 Phase 2～7（依 Phase 1 的演算法
規格）一次做完，並額外加上使用者提出的「買價 × 數量」記帳需求，做完後部署 GitHub Pages。

## 本次內容

### Phase 2：純 TypeScript prediction engine

- `src/engine/probability/`：`floatSum.ts`（Kahan–Babuska/Neumaier 精準加總）、`rangeMath.ts`（區間運算）、
  `pdf.ts`（倍率機率密度 PDF class，遞減型計算的核心）。
- `src/engine/predictor/constants.ts`：轉移機率矩陣 `PROBABILITY_MATRIX`、不知道上週型態時的穩態機率。
- `src/engine/predictor/priceGenerators.ts`：`intceil` 取整、`generate_individual_random_price`／
  `generate_decreasing_random_price`／`generate_peak_price` 的逐行移植。
- `src/engine/patterns/pattern0~3.ts`：四種 Pattern 的生成/反推邏輯，逐函式對照演算法規格表撰寫。
- `src/engine/predictor/generatePossibilities.ts`、`analyze.ts`：組裝所有候選路徑、fudge factor 重試、
  機率正規化、週保證最低/最高價、排序、全域聚合列。
- `src/engine/predictor/publicApi.ts`：友善的公開 API（`predictTurnipPrices`、`summarizePatternProbabilities`）。

### Phase 3：測試與交叉驗證

- `tests/helpers/loadVendorPredictor.ts`：在測試期動態載入 vendor 原始 `predictions.js`（不修改磁碟上的檔案），
  可以直接呼叫原始 `Predictor` class 的方法。
- `tests/crossValidation.spec.ts`：5 個情境（無資料／已知上週型態／全週遞減型路徑／已知大漲高峰單日資料／
  首次購買）把 TypeScript port 與 vendor 原始碼的輸出逐項比對，全部一致。
- `tests/patternShapes.spec.ts`：驗證遞減型單調遞減、小漲型帽子形（中間格 ≥ 左右格）、排除邏輯（超高價只剩
  大漲型存活）、不知道上週型態時機率總和為穩態分布。
- 共 20 項測試全過。

### 新增需求：記帳功能（買價 × 數量）

- `src/engine/sellStrategy/ledger.ts`：`summarizeLedger`／`projectLedgerRange`，總成本／目前總值／損益金額／
  損益百分比的算術（不涉及價格演算法本身）。
- 已寫入 `docs/專案規格書.md` 第十八節，補齊正式需求紀錄。

### Phase 4～7：UI、Pattern 機率顯示、出售決策系統、趨勢圖

- `src/engine/probability/priceRangeStats.ts`：「理論可能範圍」與「高機率範圍」分開計算（高機率範圍是依機率
  由高到低累加到 80% 覆蓋率的子集合最小/最大值，本專案自訂統計量，非 vendor 現成欄位）。
- `src/engine/sellStrategy/currentPrice.ts`：取本週已知資料中最晚一格當「目前價格」。
- `src/engine/sellStrategy/advice.ts`：🟢🟡🟠🔴 出售建議，依「機率加權的未來期望漲幅」評分，門檻依保守/平衡/
  冒險三種風險偏好調整；明確標註這層是本專案自訂邏輯、非 vendor 移植。
- `src/engine/sellStrategy/warnings.ts`：🔥 大漲型機率提高／🚨 高峰警告／⚠️ 高峰可能已結束／🚨 本週即將結束。
- `src/web/`：`storage.ts`（localStorage 持久化）、`format.ts`、`chart.ts`（純函式產生 SVG 趨勢圖字串，
  區分實際價格／高機率範圍／理論可能範圍／購入價基準線）、`main.ts`（DOM 綁定、即時重新計算、12 時段輸入格、
  清除資料二次確認）。
- `index.html`／`style.css`：手機優先、Animal Crossing 風格但無任天堂素材的柔和介面，首頁資訊順序依規格書
  十四節排列（現在該不該賣 → 最可能 Pattern → 最值得觀察時段 → 預測最高價 → 詳細機率 → 趨勢圖）。
- `build.mjs`：esbuild 把 `src/web/main.ts`（含它 import 的整個 engine）打包成根目錄 `app.js`。

### 實機驗證

用 Playwright 開無頭瀏覽器實際跑過（`run` skill 的瀏覽器驅動模式）：

- 首頁載入無 console 錯誤。
- 輸入購入價 100 後即時出現 Pattern 機率與出售建議，不需按按鈕。
- 輸入週三 AM ＝ 300（購入價 3 倍）後，四個 Pattern 機率立即更新為大漲型 100%、其餘 0%，
  出售建議變成 🔴 強烈建議出售——確認「排除所有不符合的可能曲線」的核心邏輯在瀏覽器裡是正確的。
- 修正了一個小 bug：出售建議卡片的「未來還有更高價格的機率」原本誤用帶正負號的百分比格式（顯示成
  「+85%」），已改成純機率百分比顯示（「85%」）。
